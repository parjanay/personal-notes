# Project Ideas

Capture every plausible project idea here first. Ideas may be incomplete, ambitious, or uncertain; the purpose of this file is to prevent them from being lost.

This file is only an inbox. When brainstorming begins, remove the complete idea entry from this file and create its project folder under [`project-seeds/EXPLORING/`](project-seeds/EXPLORING/). An active seed should not remain duplicated here.

## Idea Format

```markdown
### Idea name

- **Captured:** YYYY-MM-DD
- **Problem or opportunity:** One or two sentences.
- **Why it may be useful:** One or two sentences.
```
